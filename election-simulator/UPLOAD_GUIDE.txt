RIPPL ELECTION SIMULATOR — GITHUB PAGES UPLOAD GUIDE

RECOMMENDED METHOD

Replace the entire existing election-simulator folder in your published
GitHub Pages repository with the election-simulator folder contained in the
ZIP. This avoids mixing the former 119th-Congress map with the new 120th-
Congress model.

The deployed folder should contain:

election-simulator/
  index.html
  styles.css
  simulator.js
  d3.min.js
  house-districts-120.geojson
  model1-special-elections.json
  house-nominees-2026.json
  MODEL_1_METHODOLOGY.md
  README.txt
  UPLOAD_GUIDE.txt
  scripts/build-house-nominees.py
  house/index.html
  senate/index.html
  governors/index.html
  national-model/index.html

IMPORTANT CLEANUP

Delete election-simulator/house-districts-119.geojson from the repository.
The updated simulator does not use it. Keeping it is harmless to execution,
but removing it prevents an older map from being confused with the current
120th-Congress file.

MINIMUM UPDATE TO AN EXISTING INSTALLATION

If the rest of the RIPPL site is already present, replace or add these files:

1. Replace index.html and house/index.html so the new cache-busted assets load
2. Replace simulator.js
3. Replace styles.css
4. Replace senate/index.html and governors/index.html so every page references
   the same cache-busted assets
5. Replace MODEL_1_METHODOLOGY.md
6. Replace README.txt
7. Replace UPLOAD_GUIDE.txt
8. Keep house-nominees-2026.json, model1-special-elections.json, and
   house-districts-120.geojson in place
9. Delete house-districts-119.geojson if it is still present

This update makes the House output wider, adds wheel/pinch/button zoom and drag
pan to the district map, and replaces the former compact race grid with a
scrollable toss-up district results rail.

No path changes are required. The main page remains:

https://george-quinn.com/election-simulator/

After committing the upload, hard-refresh the browser so it does not reuse the
older JavaScript or district data from its cache.
